# 🎯 매수·매도 시점 분석 엔진 (v3.4)

등록 기업마다 **차트 · 뉴스 · 수급 · 밸류에이션** 신호를 각각 0~100점으로 계산하고,
가중 평균해 하나의 종합 점수(0~100)와 근거·신뢰도를 보여줍니다.

- 점수 계산: `signal-engine.js` (브라우저)
- 원천 데이터 수집: `scripts/collect_signals.py` (GitHub Actions · `live-data` 워크플로에서 회전 수집)
- 화면: 기업 실적·가치 분석 탭의 `🎯 매수·매도 시점 분석` 카드, 설정 탭의 `🎯 매수·매도 점수 가중치`

## 1. 점수 구간

| 점수 | 표시 | 색 |
|---|---|---|
| 70 ~ 100 | 매수우위 | 초록 |
| 60 ~ 70 | 매수관심 | 연초록 |
| 40 ~ 60 | 관망 | 회색 |
| 30 ~ 40 | 매도주의 | 주황 |
| 0 ~ 30 | 매도우위 | 빨강 |

50점이 중립입니다. 신뢰도가 40% 미만이면 라벨에 `(신뢰도 낮음)`을 덧붙입니다.

## 2. 규칙(플러그인) 구조

`signal-engine.js`의 `RULES` 배열이 규칙 목록입니다. 규칙 하나 = `{id, group, weight, fn}` 이고
`fn(inputs)` 이 `{avail, score, reason, bullets}` 를 돌려줍니다. 조건을 추가하려면 함수 하나와
`RULES` 항목 하나만 추가하면 되고, 그룹(차트·뉴스·수급·밸류에이션) 안에서 자동으로 가중 평균됩니다.

| id | 그룹 | 기본 가중치 | 내용 |
|---|---|---|---|
| `ma_trend` | 차트 | 25 | 5·20·60·120 이동평균 정배열/역배열, 골든·데드크로스(최근 5봉), 120일선 위치, 20일선 이격도 |
| `rsi` | 차트 | 20 | RSI(14) 과매도(<30)·과매수(>70) 구간 |
| `macd` | 차트 | 25 | MACD(12,26,9) 시그널 돌파(최근 3봉), 0선 위치, 히스토그램 방향 |
| `bollinger` | 차트 | 15 | 볼린저밴드(20, ±2σ) %B 위치(하단 이탈/상단 돌파), 밴드 폭 |
| `volume` | 차트 | 15 | 20일 평균 대비 거래량 배율 × 당일 등락(수급 유입/투매) |
| `news` | 뉴스 | 100 | 호재·악재 키워드 + 문맥 규칙(적자 탈출, 목표가 하향 등) + 시간 가중(반감기 3일) |
| `supply` | 수급 | 100 | 외국인·기관 연속 순매수 일수, 최근 순매매량/거래량 비율, 외국인 보유율 |
| `valuation` | 밸류에이션 | 100 | 52주 최고·최저 내 현재 위치(%), PER·PBR 구간 |

그룹 기본 가중치: 차트 40 · 뉴스 25 · 수급 20 · 밸류에이션 15 (설정 탭 슬라이더로 조절).

## 3. 동적 가중치와 신뢰도

- 데이터가 없는 규칙(예: 미국 종목의 외국인 수급, 뉴스 없는 종목)은 **점수에서 빠지고** 남은 규칙만으로 다시 정규화합니다.
- 신뢰도(%) = (사용 가능한 규칙의 가중치 합) ÷ (켜져 있는 규칙의 가중치 합) × 100.
- 가중치를 0으로 두거나 규칙 스위치를 끄면 그 영역은 계산에서 제외됩니다(카드에 `제외`로 표시).
- 모든 가중치가 0이면 점수를 만들지 않고 `데이터 없음`으로 표시합니다.

## 4. 장중 현재가 반영

일봉 마지막 봉의 날짜가 오늘이 아니고 현재가(시세 파일)가 종가와 다르면, **실제 현재가를 임시 봉으로 붙여**
장중 흐름을 반영합니다. 카드에 `장중 현재가 반영`으로 표시하며, 거래량은 임의로 만들지 않습니다(0).

## 5. 데이터 파일

수집기는 종목별 파일로 나눠 저장합니다(앱은 보고 있는 종목 하나만 받습니다).

```
data/signal/h/<종목코드>.json   종목 1개 (약 7KB)
data/signal/manifest.json       수집 대상 목록·갱신 시각(설정 화면 상태 표시)
```

```json
{
  "schema": 1, "code": "005930", "name": "삼성전자", "market": "KR", "currency": "KRW",
  "updated_at": "2026-11-26T05:04:52+09:00", "price": 166900,
  "bars": [[20261125, 178500, 179900, 166000, 166900, 21801583, 45.9], "… 120거래일"],
  "supply": {"asof": "20261125", "days": [{"d": "20261125", "f": -5763083, "o": -948317, "i": 6534711, "rate": 45.8}]},
  "valuation": {"per": 5.25, "pbr": 1.8, "eps": 31809, "bps": 92903,
                "high52": 380000, "low52": 99300, "div": 1.0, "foreign_rate": 45.9}
}
```

- `bars` 항목: `[날짜(YYYYMMDD), 시가, 고가, 저가, 종가, 거래량, 외국인소진율]` — 미국 종목은 마지막 값이 `null`.
- `supply.days`: 최근 10거래일 중 네이버가 주는 만큼(보통 5일). `f` 외국인, `o` 기관, `i` 개인 순매매량.

## 6. 수집 운영

```
python3 scripts/collect_signals.py                     # 예산(기본 120초) 안에서 회전 수집
python3 scripts/collect_signals.py --limit 50          # 이번 실행 50종목
python3 scripts/collect_signals.py --force --workers 4 # 초기 적재·강제 갱신
python3 scripts/collect_signals.py --check             # 파일 쓰지 않고 현황만
```

- 대상: `data/config.json` 등록 종목 + 국내 시가총액 상위 420 + 미국 상위 110 (환경변수 `SIGNAL_KR_COVER`, `SIGNAL_US_COVER`).
- 원천: 국내 `api.finance.naver.com/siseJson.naver`(일봉) · `m.stock.naver.com/api/stock/<코드>/integration`(수급·밸류에이션),
  미국 `query1.finance.yahoo.com/v8/finance/chart/<심볼>`.
- 한 번 받은 종목은 20시간 동안 재사용합니다. 오래된 종목 → 한 번도 못 받은 종목 순으로 회전합니다.
- 실행 예산은 `COLLECT_SIGNAL_BUDGET_SECONDS`(기본 120초)이며, 초과하면 남은 종목은 다음 실행으로 넘깁니다.
- GitHub Actions에서는 `live-data.yml`의 `collect_live_data.py`가 끝난 뒤 자동으로 호출되고,
  수집기가 직접 새 파일을 `git add` 합니다(워크플로 파일은 workflows 권한이 없어 수정하지 않습니다).
- 실패해도 직전 파일을 그대로 둡니다(가짜 값 금지). 봉이 20개 미만인 응답은 저장하지 않습니다.

## 7. 한계

- 뉴스 감성은 키워드·문맥 규칙 기반이라 반어·복합 문장은 놓칠 수 있습니다. 근거 헤드라인을 함께 보여 주는 이유입니다.
- 이 점수는 참고 지표이며 투자 판단과 책임은 사용자에게 있습니다.
